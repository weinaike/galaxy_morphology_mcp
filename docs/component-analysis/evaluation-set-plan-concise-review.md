# 星系成分分析评测集建设方案（审阅版）

> 日期：2026-09-09
> 状态：方案待确认，评测集尚未正式抽取
> 详细实施依据：`docs/component-analysis/evaluation-set-design.md`

## 一、建设目标

从已有的单波段和多波段历史拟合数据中，抽取一批证据充分、结果可信的成分分析决策样本，用于客观评测后续优化是否有效。

每条样本回答一个问题：给定某一轮拟合结束时能够看到的图像、残差、模型、参数和历史状态，成分分析模块能否给出正确的下一步决策。

评测范围包括添加、删除、替换成分，调整参数／约束，以及满足条件时输出 `CONVERGED`。v1 只覆盖 Image 拟合，不包含 SED 和 Image-SED，也不评测完整自主拟合流程。

## 二、数据基础

- 单波段数据：包含 100 个 Gadotti 专家标签对象、25 个 JWST F277W 专家标签对象，以及相应的多批次历史拟合过程。
- 多波段数据：包含 32 个具有 confirmed 专家终态标签的对象，以及 13 个历史拟合批次。
- 专家标签提供最终应有的成分集合和成分语义，不提供专家逐轮操作过程。
- 单波段 JWST F277W 中 4 个 `elliptical` 对象统一标记为 `single_sersic`，使用 Sersic 模型；它们与使用 `expdisk` 模型的 `disk` 明确区分。

历史数据数量较多，但存在重复批次、对象别名、证据缺失和部分拟合未达到专家终态等情况，因此原始轮次不能直接作为评测答案，需要经过筛选和裁决。

## 三、样本构建原则

1. **不直接采信历史动作**：历史轨迹由 Agent／MCP 产生，不是专家示范。每个动作都要重新核验。
2. **同时检查动作前后证据**：动作前必须有残差、参数、约束或成分缺失等可观察依据；动作后必须拟合有效，且没有产生更严重的问题。
3. **参考专家终态判断方向**：动作应使模型结构更接近专家成分集合，或修复阻止继续拟合的明确问题。
4. **允许局部正确**：即使某次历史拟合最终没有达到专家标签，其中证据充分的中间动作仍可纳入评测集。
5. **严格控制信息泄漏**：评测输入不能包含下一轮结果、最终报告、历史动作结论或最佳轮次答案。
6. **只保留可复现样本**：无法恢复唯一动作、缺少关键拟合产物或只有文字说明的复合动作，不进入核心评测集。

`CONVERGED` 不单独建立最佳轮次选择任务。只有历史选定的最佳轮次同时满足专家成分一致、拟合有效、残差无明显系统结构和参数健康要求时，才作为正确的终止决策。

## 四、执行流程

1. 建立单波段和多波段数据源清单，过滤无专家标签、SED／Image-SED 和关键产物不完整的数据。
2. 恢复相邻轮次关系及真实配置差异，识别每轮实际执行的决策。
3. 按对象、输入状态和动作内容生成稳定指纹，消除跨批次重复数据。
4. 为每条候选样本构建无未来信息的评测输入，并记录源文件校验信息。
5. 自动提取成分差异、拟合收敛、BIC、残差、参数边界和约束等裁决证据。
6. 对候选动作逐条审查，只将“正确且证据充分”的样本纳入核心评测集。
7. 冻结评测集版本，并用当前成分分析模块完成一次基线评测。

整个抽取过程只读访问历史拟合数据，不修改原始结果，也不重新执行 GALFIT／GalfitS。

## 五、交付结果

- 核心评测集：用于计算正式评测指标，只包含 `CORRECT + high confidence` 样本。
- 审计数据：保留试探、错误或不安全动作，供问题归因和追溯，不参与主指标。
- 排除清单：记录因证据缺失、动作不唯一或数据不完整而未纳入的项目及原因。
- 数据清单与版本说明：记录数据来源、文件校验值、语义规则、去重结果和样本统计。
- 基线评测报告：分别报告单波段、多波段、各动作类型和对象级结果。

核心指标包括动作类型准确率、目标成分准确率、参数调整准确性、不安全动作率和 `CONVERGED` 精确率。评测结果同时报告样本数量和星系数量，避免把同一星系的多个轮次误当作相互独立的对象。

## 六、范围控制

- 本评测集只用于评测，不用于训练、规则调参或 prompt 调优，因此不划分训练集、验证集和测试集。
- 不预设最终样本数量，以完成全量审计后符合严格准入条件的数量为准。
- Gadotti 参数值暂不作为数值真值；参数恢复能力如需评测，后续单独建设子评测集。
- v1 不覆盖 SED、Image-SED、完整 rollout 和候选拟合接受／拒绝判断。
