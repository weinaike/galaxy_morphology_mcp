# JWST0716 成分分析：原始 residual_analysis 决策与新 VLM shadow 对比

更新日期：2026-08-24

## 结论

本报告已修正旧方案口径。旧方案是每个历史轮次由 residual_analysis.py 原始流程写入 all_bands_comparison_component_analysis_*.md 的最终调整建议；它不是 numeric-only shadow baseline。

两套方案的输出粒度不同，不能把它们压缩为“动作变化轮数”或按单一动作计算准确率：原始流程可在同一轮同时建议新增、删除、替换 profile、改变 Fourier 项和收紧参数约束；新 VLM shadow 每轮只输出一个最终结构动作 PROPOSE_ADD 或 KEEP_AND_CONTINUE。逐轮表因此同时保留旧决策摘要、辅助方向标签、新方案最终动作、当前成分和专家终态。

专家标签是对象最终拟合的成分集合，并不是历史每轮的动作真值。新方案新增的成分位于终态中时记为“方向一致”；终态外新增只列为人工复核优先项，不能据此直接判定错误。Edge-on Disk 按既定范围保留事实记录，但不据此评价或优化。

## 动作方向

### 新方案：完整 VLM shadow 的最终动作

本批 116 轮历史 VLM shadow 的最终动作为 48 轮 PROPOSE_ADD、68 轮 KEEP_AND_CONTINUE。PROPOSE_ADD 细分为 companion 18、bar 14、bulge 11、fourier_m1 4、disk 1。该批使用 gemini-3.1-pro-preview；97 轮严格解析成功，19 轮 PARSE_FAILED 后按数值降级，runner failures 为 0。

| 最终动作方向 | 解释 |
|---|---|
| PROPOSE_ADD disk | 数值层的延展尺度、外层几何和系统性残差满足规则门槛。 |
| PROPOSE_ADD bulge | 中心过量和可分辨性数值证据满足门槛；中心语义按方案 B 由数值分流。 |
| PROPOSE_ADD bar | 数值 Bar 证据、分辨率和 PSF 排除门槛通过，必要时结合 VLM 形态观察。 |
| PROPOSE_ADD companion | 数值候选与独立源形态观察共同支持；候选编号由数值 overlay 定位。 |
| PROPOSE_ADD fourier_m1 | 原图 m=1 数值振幅达到阈值，且无 m=1 混淆证据。 |
| KEEP_AND_CONTINUE | 没有满足直接结构提议条件，或冲突／降级证据由 policy 保守处理。 |
