# workflow_galfit_s1 — Expert-Guided Single-Band Galaxy Fitting Workflow

要求严格遵循工作流开展星系拟合分析工作。
仅关注拟合盘、核球、侧视盘、棒、AGN核、偏心、伴星系、Lens这八种物理成分，仅可对这八种成分的残差添加模型成分拟合，其他残差特征可以选择保留不拟合。
图像分析与拟合执行只能使用 galmcp 中的工具。严禁使用4_5v_mcp的相关工具。
系统规定的规范、component_analysis的决策、以及 `best-round-verifier` subagent的审计结果是你需要遵循的，严禁私自更改。

## 专家指定的成分组合（expert_components）

本 workflow 在调用时除传入 feedme 文件路径外，还会接收人类专家提供的目标星系形态结构组成（expert_components）。
专家成分组合的格式为：**`成分(候选模型,候选模型,...)`** ，多个成分之间用英文逗号分隔。

**示例：** `bulge(sersic,psf), disk(sersic), bar(sersic)` 含义为：
- bulge 成分：可使用 sersic 或 psf 模型拟合，在候选模型之间择优选用
- disk 成分：使用 sersic 模型拟合
- bar 成分：使用 sersic 模型拟合

**解析与约束规则：**
- 圆括号内为该成分允许使用的候选模型列表，拟合过程中可在候选模型间切换
- 专家指定成分列表 **T** 即为本星系的目标成分组合，最终模型必须严格匹配 T（数量与类型一致，不可超出）
- 不允许添加 T 之外的成分；当模型成分组合 == T 后，不再增删成分

## workflow

阶段一. 查看星系目录与原图分析
* **查看星系目录：** 确认所需的文件是存在的，包括 FITS 图像、掩膜文件、背景估计文件、feedme 文件等。
* **查看原始数据与图像：** 使用 render_original 生成原图、view_original_image 分析生成图、detect_bar_lopsidedness 工具检测成分，综合分析确认星系的初始基本形态特征（星系类型与成份预测）。这将为后续的拟合提供初始猜测值。

阶段二. 结构搜索与动态校验 (Structure Search & Dynamic Validation)
*目标：以专家指定的成分组合 T 为目标，从单成分开始，每轮增加一个成分，逐步达到 T。当达到 T 后，固定成分组合，仅微调参数与约束。不追求参数极致收敛。*

* 步骤0. **解析专家成分组合：** 解析 `{expert_components}`，得到目标成分集合 T = {c1, c2, ..., cN} 及每个成分的候选模型列表。本阶段的拟合任务为：从单一成分（如 disk 或 bulge）开始拟合，每轮 +1 成分，直到模型成分组合 == T。

* 步骤1. 拟合与调参：使用 run_galfit，执行星系拟合（要求输入配置文件绝对路径），
  - 请查看日志确认拟合是否正常。如果拟合异常，需要调初始值与调约束（调初始值优先级高于增加约束；非必要不加.cons(x,y除外)），重新拟合, 才能进入步骤2。
  - 本阶段要遵循 component_analysis 的分析结果（即成分修改建议），只能够微调参数和约束、不能够改变 component_analysis 要求的成分数量和类型。

* 步骤2. **成分调整：** 使用 `component_analysis` 分析当前模型的成分配置，获取成分增删和参数调整策略；严格遵循策略，修改配置，执行步骤1。
    - 每次调用 `component_analysis` 前，需要创建或者更新当前星系目录下的 `working_note.md`, 将上一轮次的`成分分析要点`、`拟合目标`和`拟合进展`形成摘要加到文件末尾。
    - 针对同一个源多轮拟合， 所以要求 working_note 所记录的`拟合目标`要求有连续性，基于新的判断或者证据，目标调整需要说明。要求保持拟合目标的持续性和一致性，避免频繁大幅调整目标导致分析的混乱。
    - **调用 component_analysis 时，custom_instructions 字段必须包含以下三项内容：**
        1. **科学目标（专家判断）：** "实现专家指定的成分组合：`{expert_components}`；本轮的拟合目标是把模型成分组合向 T 收敛"
        2. **专家提供的成分与候选模型清单：** 解析 expert_components 后得到的 T 及每个成分的候选模型（如 "bulge: sersic/psf, disk: sersic, bar: sersic"）
        3. **working_note 路径：** 当前星系目录下 working_note.md 的绝对路径

* 步骤间推进规则（贯穿步骤1-2的迭代）：
    - 当 **当前模型成分组合 ⊊ T** 时：依据 component_analysis 建议，从 T 中尚未加入的成分里选取 **恰好一个** 加入，进入下一轮步骤1-2。严禁一次增加多个成分，严禁添加 T 之外的成分。
    - 当 **当前模型成分组合 == T** 时：不再增删成分，转入步骤3。

* 步骤3. 物理意义分析 与 奥卡姆剃刀原则 过滤不物理的情况
    - 物理意义分析：严格遵循"物理意义分析与策略"，逐条分析成分参数是否符合物理意义。
        - 如果出现不物理的情况，需在该成分的候选模型之间切换（例如 bulge 在 sersic / psf 之间切换）；若所有候选模型均不物理，回到`步骤2`重新拟合。
    - "奥卡姆剃刀原则"：在专家指定成分组合 T 的范围内执行。成分数量固定为 |T|，不增不减；但可在候选模型之间择优。
        - 任何调整都不可让最终成分组合偏离专家指定 T。
        - 如果所有候选方案都已尝试且无法改善，进入步骤4。

* 步骤4. 锁定最佳结果与物理意义解读
    - 锁定最佳结果
        - 依据<最优轮次锁定的标准>进行轮次选择，要求分析 "成分条件"、"拟合条件"、"物理条件"、"参数条件"、"校验条件"和"指标条件"，选择候选最优轮次。
        - 优先在 **成分组合 == T** 的轮次中择优。
        - 需要详细说明显选择理由，并给出其对应的形态学物理意义（如：成分 A 代表经典的盘结构，成分 B 代表致密的核心星团）。
        - **正式落锁前，必须调用 subagent `best-round-verifier`** 对候选轮做独立审计，**`FAIL` 严禁落锁**，按"阻断性问题"修复后复审至 `PASS`；`PASS`（含 WARN）方可落锁。

阶段三. 科学目标校准与报告撰写
* 科学目标校准：科学目标关心偏心的影响，如果最佳结果不包含 Fourier 成分，调用 fourier_mode_analysis 对残差图进行分析判断是否需要采用 fourier mode 对偏心非对称残差拟合。如果已经包含 Fourier 成分，则跳过该步骤。
    - 只能使用 1 阶 Fourier 模式进行拟合补偿。且只能作用于 Disk 成分 或者 是单 Sersic 模型（如果没有 Disk 成分）。
    - F1 成分的 amplitude 大于 0.02，且拟合质量没有恶化 就可以保留；更新最佳轮次为带 F1 的最新轮次。否则放弃 F1 成分，保持原来的最佳轮次。

* 报告撰写：使用 `write_file` 工具将分析结论写入当前星系目录：`analysis_report_xxx.md`。
* **报告内容包含：**
    * **预处理信息：** 掩膜说明、背景设定依据。
    * **专家指定成分组合：** 列出 expert_components 的原始内容、解析后的 T、以及每个成分最终采用的模型选择。
    * **迭代过程流水账：** 每轮新增/删除成分的依据（多模态视觉判断记录）、参数发散与回退记录。
    * **最佳结果锁定分析与结果：** 最佳结果的锁定理由、最终采用的参数表、物理意义解读。
    * **附件索引：** 最佳轮次的目录路径、最终的 `feedme` 文件、最终的拟合对比图（原图/模型/残差）路径。
    * **json格式化输出：** 在文档最后格式化输出轮次信息，便于规则提取，自动化处理。格式如下：
    ```json
    {"best_turn":"<最佳轮次的目录名>","components":["<最优轮次包含的哪些物理成分>"],"galaxy_type":"edge-on/face-on/elliptical"}
    ```
    其中 best_turn 的值为 archives/ 下最佳轮次子目录的名称（如 20260414T093323.c1993a48）。
    物理成分类型：[Disk,Bulge,Bar,Nucleus,Companion,Fourier,SingleSersic,Lens]
    galaxy_type:可选的是正向盘、侧向盘、椭圆星系三种。即：[edge-on,face-on,elliptical],如果盘星系的 Disk成分的 q<0.3，则认定为侧向盘
